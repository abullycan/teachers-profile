# Инструкция по заполнению сайта

На сайте есть файл `content.js`, который нужно редактировать только при добавлении фотографии.

## Как добавить фотографию

1. Подготовьте хорошую вертикальную фотографию. Лучше, если на ней хорошо видно лицо, а фон не слишком пёстрый.
2. Положите фотографию в ту же папку, где находятся `index.html` и `content.js`.
3. Откройте файл `content.js` в обычном текстовом редакторе.
4. Найдите строку:

```js
photo: "",
```

5. Впишите точное имя файла между кавычками. Например:

```js
photo: "zhanna.jpg",
```

6. Сохраните файл. Название должно совпадать полностью, включая `.jpg`, `.png` или `.webp`.

## Как добавить диплом

На сайте уже есть аккуратный блок «Высшее педагогическое образование». Сам диплом можно добавить туда позже, если захочется показать документ.

Перед публикацией лучше закрыть или обрезать серию и номер диплома, регистрационный номер и другие данные, которые не нужны посетителям сайта. Фамилию, имя, название учебного заведения и квалификацию можно оставить, если тебе комфортно.

1. Подготовьте безопасное фото или фрагмент диплома.
2. Положите файл в ту же папку, где находятся `index.html` и `content.js`.
3. В `content.js` найдите:

```js
diploma: ""
```

4. Укажите имя файла, например:

```js
diploma: "diploma.jpg"
```

5. Сохраните файл и обновите сайт.

Если диплом не добавлять, текстовая карточка об образовании всё равно останется на странице.

## Как добавить отзывы

Отзывы на сайте уже предусмотрены и оформляются как картинки (например, скриншот переписки в WhatsApp или VK). Пока их нет, отображаются аккуратные места-заглушки.

1. Подготовьте скриншоты отзывов. При желании обрежьте лишнее (номер телефона, аватар, посторонние сообщения).
2. Положите файлы изображений в ту же папку, где находятся `index.html` и `content.js`.
3. В `content.js` найдите блок:

```js
reviews: [
  { image: "" },
  { image: "" },
  { image: "" }
]
```

4. Впишите имя файла в поле `image`:

```js
reviews: [
  { image: "review1.jpg" },
  { image: "review2.jpg" },
  { image: "review3.png" }
]
```

Можно оставить от одного до шести отзывов — если нужно больше трёх, просто добавьте ещё строки `{ image: "" }` по тому же образцу. Добавляй только настоящие отзывы и лучше заранее получай разрешение на публикацию у автора.

**Рекомендации к изображениям:**
- Формат: PNG (для скриншотов переписки) или JPG (для фото/скана отзыва).
- Ширина: 600–900 px — этого достаточно для чёткости.
- Вес файла: желательно не больше 300–500 КБ, чтобы страница быстро грузилась.
- Если скриншот длинный, лучше обрезать до самого текста отзыва, а не сжимать целиком — так он останется читаемым.

## Важные правила

- Не удаляйте кавычки, запятые и квадратные скобки.
- После изменений сохраните `content.js` и откройте `index.html` заново.
- Если фотография не появилась, проверьте точное имя файла и расширение.

## Как отправлять сайт людям

Для публикации на GitHub Pages или другом хостинге загрузите вместе все файлы:

- `index.html`
- `content.js`
- фотографию, если она добавлена

Файл `INSTRUCTION.md` можно не загружать на сайт, он нужен только как памятка.
